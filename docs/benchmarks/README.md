# PHANATIC benchmarks

This directory will contain workload definitions, runner scripts, environment metadata, and raw results.

## Rules

- Compare equivalent guest images, game/app versions, resolution, graphics settings, and power conditions.
- Record host model/chip, RAM, macOS version, runtime version, guest API level, and test duration.
- Report distributions (especially frame times), not only averages.
- Separate emulator startup, guest boot, app launch, and gameplay measurements.
- Do not publish comparative performance claims from unmatched configurations.
