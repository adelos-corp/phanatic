# Licensing and redistribution register

No project-wide license has been selected. Before public distribution, decide a license and review all third-party license and trademark obligations with appropriate care.

| Component | Planned use | License / redistribution review |
|---|---|---|
| Rust toolchain and dependencies | Native core | Track dependency licenses and notices |
| Tauri | Desktop shell | Verify version and dependency notices |
| React / TypeScript | UI | Verify dependency notices |
| Android SDK Platform Tools | ADB | Review current Android SDK license and redistribution terms |
| Android Emulator | Runtime | Review current component terms and packaging rights |
| AOSP / system images | Guest OS | Image-specific license and redistribution review required |
| QEMU-derived components | Potential runtime component | Component-specific license review required |

Do not bundle or redistribute an image or binary just because it can be downloaded by the developer. Record the exact source, version, license, and any notices required.
